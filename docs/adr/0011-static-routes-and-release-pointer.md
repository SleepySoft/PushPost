# ADR-0011：固定文章路由并使用原子 release 指针

- 日期：2026-10-26
- 状态：Accepted

## 背景

目录是机械分类，如果文章 URL 包含分类，移动文章会破坏已有链接。Windows 本地环境又不能依赖需要额外权限的目录符号链接。

## 决策

文章路由固定为 `/posts/<slug>/`，分类为 `/categories/<URL 编码目录名>/`，另提供 `/tags/`、`/archive/` 和 `/rss.xml`。文章移动分类不改变文章 URL，slug 变化通过 `metadata/redirects.yml` 指向稳定文章 ID。

每次构建写入独立 release 目录。静态服务读取原子替换的 `current.json` 指针，不使用 Windows 目录符号链接。公开资源仅从对应快照缓存复制，旧任务和旧 release 不读取可变 Git 工作区。

## 后果

- 分类重命名只影响分类页，不改变文章永久链接。
- 当前指针替换失败可恢复旧版本，Windows 与 Linux 使用相同逻辑。
- 需要保存 release 和快照资源，并制定备份与清理策略。
- 分类页重命名需要单独配置重定向，不由文章重定向自动推导。

## 备选方案

- **文章 URL 包含目录**：结构直观，但移动分类破坏链接。
- **`current` 符号链接**：常见但 Windows 权限和语义不一致。
- **每次原地覆盖静态目录**：构建失败可能损坏公开站，违背 ADR-0008。
