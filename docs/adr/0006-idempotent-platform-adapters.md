# ADR-0006：通过异步任务和适配器实现幂等分发

- 日期：2026-10-26
- 状态：Proposed

## 背景

第三方平台在格式、认证、资源上传和写入能力上差异明显，网络调用还可能超时或返回模糊结果。同步执行会拖慢主站部署，简单重试又可能创建重复文章。

## 决策

每个平台以独立适配器实现，统一执行校验、转换、资源上传、创建/更新和结果记录。分发通过持久化异步任务运行，按文章、平台账号、操作和源版本记录状态。

系统采用“至少一次执行、业务效果幂等”的目标：

- 对活动任务施加唯一性约束和 worker 锁。
- 优先复用已保存的远端对象 ID 执行更新。
- 可恢复错误有限重试并退避。
- 创建结果未知时优先查询核对；无法核对则转人工，不盲目重建。
- 无官方写入能力的平台使用导出与人工登记，不实现隐蔽模拟登录。

## 后果

- 平台故障可独立恢复，主站不被阻塞。
- 每增加一个平台都需要契约测试和真实账号验证。
- 并非所有平台都能实现完全自动幂等，必须暴露 `manual_required` 等状态。
- 远端映射和任务历史成为重要数据，需要备份。

## 备选方案

- **部署时同步调用所有平台**：延迟高且故障相互影响，拒绝。
- **失败后统一重新创建**：会产生重复远端文章，拒绝。
- **浏览器自动化所有平台**：脆弱且带来账号安全风险，不作为核心方案。
